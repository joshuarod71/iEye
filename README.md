# 👁️ iEye Protocol: The Unblinking Witness

> **"We don't need permission to tell the truth. We are the witnesses. We are the evidence. We are iEye."**

iEye is a decentralized, serverless video protocol designed for the **True Free Press.** It turns every mobile device into a global node of accountability. No accounts, no central servers, and no delete buttons.

---

## 🚀 The Vision
In a world of "shadowbanning" and "redaction," iEye provides an immutable layer of truth. It is a peer-to-peer (P2P) network where live video is shared directly between citizens.

### Why iEye?
* **Zero Trust:** No central authority can "turn off" a stream or delete evidence.
* **Serverless:** Powered by WebRTC and DHT. The more people watch, the stronger the network.
* **Accountability:** Built-in mechanisms to ensure that when the public sees a crime, the "system" cannot ignore it.

---

## 🔴 The Justice Cycle
The map evolves based on the collective weight of the witnesses.

1. **Active (Blue/Green):** A live stream is in progress.
2. **The "Bust" (Red):** One witness clicks "Bust" to save the last 60 seconds. The Eye turns **Red**.
3. **Under Review (Purple):** An investigator signs the evidence. The community starts the clock.
4. **The Bullshit Detector (💩):** If a Purple Eye is unresolved for **30 days**, it turns into a **Poop Emoji**.

## 🛠️ For The Nerds (Architecture)
We are building a lean, "Virus-style" protocol.
* **Constraint:** The core client logic must remain under **50KB**.
* **Stack:** Vanilla JS, WebRTC, IPFS/Arweave.
* **Audit:** All pull requests are AI-audited for backdoors.
